# 旅行足跡

記錄去過的地方和拍的照片，全部標在地圖上。可以加到手機主畫面，離線也能看。

## 功能

- **記錄這裡**：自動抓目前位置，也可以點地圖選位置；照片有拍攝地點、日期時會自動帶入。可加多張照片（拍照或從相簿選）、地點名稱、日期和心得。
- **足跡列表**：依月份分組，新的在前面；可以看大圖、編輯、刪除，或用 Google 地圖導航回去。
- **足跡地圖**：所有去過的地方都標在地圖上，有照片的用照片當標記。
- **備份**：匯出成 JSON 檔（含照片），可以在其他手機匯入；已存在的足跡不會重複加入。

## 資料存在哪裡

- 足跡與照片存在瀏覽器的 IndexedDB，只在這支手機上，不會上傳。
- 照片儲存前會縮小（原圖最長邊 1600px、縮圖 400px，JPEG）。
- 清除瀏覽器資料、刪除主畫面 App 或換手機前，請先匯出備份。
- 地圖圖片來自 OpenStreetMap，只下載地圖，不會傳送足跡資料。

## 開發

- 沒有建置步驟：在專案根目錄執行 `python3 -m http.server 8000`，打開 `http://localhost:8000/footprints/`。
- 不碰畫面的邏輯（讀照片 EXIF、依月份分組、備份檢查）在 `logic.js`，測試在 `tests/`：在 `footprints/` 執行 `node --test`。
- 修改檔案後，請把 `sw.js` 的 `CACHE_VERSION` 加 1。
