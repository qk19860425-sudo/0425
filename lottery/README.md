# 交換禮物抽籤機

交換禮物用的抽籤 App，可以加到手機主畫面，離線也能用。

## 使用方式

1. 輸入起始號碼和結束號碼（例如 1～12），需要的話填「不要抽的號碼」（例如 `4, 13` 或 `8-9`）。
2. 按「確定，開始抽籤」。
3. 大家輪流按「抽一個！」，抽到的號碼會用大字顯示；抽過的號碼不會再出現。
4. 按「放大號碼」可以全螢幕顯示號碼給大家看。

### 不會抽到自己的禮物

勾選後，每個人依自己的號碼順序輪流抽（1 號的人先抽、再來 2 號……），
保證沒有人抽到自己帶來的禮物，最後一個人也不會卡住。至少要 2 個號碼。

## 其他

- 一次最多 500 個號碼。
- 抽籤紀錄存在這台手機的瀏覽器裡，重新整理或關掉 App 都不會不見；按「同樣號碼重新抽」或「重新設定號碼」才會清除。
- 亂數使用瀏覽器內建的 `crypto.getRandomValues`。

## 開發

- 沒有建置步驟：在專案根目錄執行 `python3 -m http.server 8000`，打開 `http://localhost:8000/lottery/`。
- 抽籤邏輯在 `logic.js`，測試在 `tests/`：在 `lottery/` 資料夾執行 `node --test`（Node.js 18 以上）。
- 修改檔案後，請把 `sw.js` 的 `CACHE_VERSION` 加 1，手機上的 App 才會換成新版。
