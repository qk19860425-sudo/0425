# 大阪旅遊（原型）

手機優先的繁體中文旅遊 Web App，第一版以大阪為範例。首頁有三個入口：

- **機場交通**：關西國際機場 → 難波／梅田，比較鐵路、機場巴士、計程車，可依費用或時間排序。
- **景點**：依區域、類型篩選。
- **美食**：依區域、料理類型、價位篩選。

目前使用本機的**示範資料**，畫面上有「示範資料」標示。美食店家是虛構的示範店名。

## 啟動方式

純 HTML／CSS／JavaScript，不需要安裝套件或建置。

**方法 1：直接開檔案**

用瀏覽器打開 `osaka/index.html` 即可。

**方法 2：用本機伺服器（建議，和上線後的行為一致）**

在程式庫根目錄執行：

```bash
python3 -m http.server 8000
```

再用瀏覽器開 <http://localhost:8000/osaka/>。手機要測試時，手機和電腦連同一個 Wi-Fi，改開 `http://電腦的區網 IP:8000/osaka/`。

## 修改資料

資料和介面分開，**只改 `data/` 資料夾就能更新內容**，改完重新整理頁面即可。

| 要改的內容 | 檔案 | 說明 |
| --- | --- | --- |
| 機場交通 | `data/transport.js` | `destinations` 是目的地（難波、梅田）；`options` 是每一種交通方式 |
| 景點 | `data/spots.js` | `areas`、`types` 是篩選選項；`items` 是每個景點 |
| 美食 | `data/food.js` | `areas`、`cuisines`、`priceLevels` 是篩選選項；`items` 是每家店 |

每個檔案開頭都有欄位說明。常見修改方式：

- **新增一筆**：複製一筆現有資料，改內容，並給一個不重複的 `id`。
- **新增篩選選項**：先在 `areas`／`types`／`cuisines` 加上選項，資料裡才能使用。
- **交通費用**：`fareMin`、`fareMax` 填數字（日圓），只有一個金額就兩個都填一樣；`minutes` 填分鐘數；`transfers` 填轉乘次數（0 是直達）。
- **美食價位**：`price` 填 1、2、3，對應 `priceLevels`。

資料寫錯時（例如區域拼錯、價位不存在、`id` 重複），頁面上方會出現紅色的「資料格式有問題」提示。

## 程式結構

```
osaka/
├── index.html        頁面結構（首頁與三個功能頁）
├── style.css         樣式（手機優先，支援深色模式）
├── data/             資料（只改這裡就能更新內容）
│   ├── transport.js
│   ├── spots.js
│   └── food.js
├── js/
│   ├── logic.js      排序、篩選、格式化、資料檢查（不碰畫面，可測試）
│   └── app.js        畫面與操作
└── tests/
    └── logic.test.js 邏輯與資料測試
```

## 測試

需要 Node.js 18 以上。在 `osaka/` 資料夾執行：

```bash
node --test
```

測試內容：交通依費用／時間排序、景點與美食篩選、金額與時間格式、資料檔格式檢查。修改 `data/` 後也建議跑一次，確認資料沒有寫錯。
